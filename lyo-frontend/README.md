# LYO Frontend v2.0

React 18 + TypeScript + Tailwind CSS + Vite social media frontend.

## Features
- Feed with infinite scroll & stories
- Direct Messages & Group Chats (real-time)
- Stories viewer (24h ephemeral)
- Live Streaming with real-time chat
- Admin Dashboard (moderation queue, reports, users, analytics)
- Dark mode support
- Responsive design (mobile + desktop)

## Tech Stack
- React 18 + TypeScript
- Tailwind CSS + Vite
- Zustand (state management)
- TanStack Query (data fetching)
- Socket.IO (real-time)
- React Hook Form + Zod (forms)
- Framer Motion (animations)

## Quick Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
